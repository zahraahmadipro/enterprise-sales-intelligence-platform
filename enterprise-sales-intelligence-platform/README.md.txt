# Enterprise Sales Intelligence Platform

An enterprise-level Sales Intelligence Data Warehouse project built using SQL Server, ETL pipelines, dimensional modeling, and Power BI.

---

## Technologies Used

- SQL Server
- T-SQL
- ETL Pipelines
- Data Warehouse
- Star Schema
- Power BI
- Incremental Loading
- Data Quality Checks

---

## Architecture

OLTP Database → Staging Layer → Data Warehouse → BI Views → Power BI Dashboard

---

## Features

- Enterprise ETL Pipeline
- Star Schema Design
- Fact and Dimension Tables
- ETL Logging
- Incremental Loading
- Business Intelligence Views
- Data Quality Validation

---
